Collaboration images
====================

Put images for the Collaborations section in this folder, then run:  npm run images

Name each file after the collaboration's id (see lib/collabs.ts):

  {id}-logo.png   The other game's logo. Shown on the timeline card and in the detail view.
  {id}.png        Key art for the detail view.

.png, .jpg, .jpeg and .webp all work. Transparent PNG logos look best.

Ids: dynamix, stellights, lanota, tone-sphere, groove-coaster, chunithm, ongeki, maimai,
     wacca, muse-dash, cytus-ii, rotaeno, undertale, djmax, arknights
